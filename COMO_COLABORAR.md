## 👥 **Formas de Participar**

### **🌟 Opción 1: Ver el Proyecto**
- **Acceso**: Solo lectura
- **Ideal**: Para aprender y usar la aplicación
- **Pasos**: Solo visita el enlace

### **🍴 Opción 2: Fork (Recomendado)**
- **Acceso**: Tu propia copia para modificar
- **Ideal**: Para hacer mejoras personalizadas
- **Pasos**:
  1. Ve al repositorio principal
  2. Click en "Fork" (arriba a la derecha)
  3. Trabaja en tu copia
  4. Si quieres compartir mejoras, haz Pull Request

### **👥 Opción 3: Colaborador Directo**
- **Acceso**: Escritura en el repositorio principal
- **Ideal**: Para trabajo en equipo
- **Pasos**:
  1. Contacta al administrador
  2. Solicita acceso como colaborador
  3. Recibirás invitación por email

## 🛠️ **Cómo Usar el Proyecto**

### **Para Usuarios Finales**
1. **Descarga el código**:
   ```bash
   git clone https://github.com/Christian060104/MideTuEstres.git
   ```
2. **Configura el backend**:
   - Ejecuta `docker-compose -f mysql-only.yml up -d`
   - Conecta MySQL Workbench a localhost:3306
   - Ejecuta el script SQL
3. **Inicia el servidor**:
   ```bash
   cd backend
   php -S localhost:8000 server.php
   ```
4. **Abre la aplicación**:
   - Frontend: Abre `index.html` en tu navegador
   - Backend: http://localhost:8000

### **Para Desarrolladores**
1. **Haz Fork** del repositorio
2. **Clona tu versión**:
   ```bash
   git clone https://github.com/TU_USUARIO/MideTuEstres.git
   ```
3. **Crea una rama** para tus cambios:
   ```bash
   git checkout -b mi-mejora
   ```
4. **Haz tus cambios** y commitea:
   ```bash
   git add .
   git commit -m "Mi mejora específica"
   ```
5. **Sube y comparte**:
   ```bash
   git push origin mi-mejora
   ```
